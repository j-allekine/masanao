# Meal Schedule as the Issuance Context

An Activity may contain multiple Meal Schedules, each with its own user-entered name or description and selected time. The Meal Schedule is the direct context for its issuance, so the MVP does not introduce a separate Schedule Entry layer. This matches how staff think about Lunch, Snack, or Feeding as distinct scheduled occasions and removes an unnecessary indirection from the workflow.
